## ✨ Features

- 💼 **Live Job Search** - Real-time job listings integration with location filtering
- 🤖 **Grok 4 AI Assistant** - Career advice and guidance from Grok 4 Edition
- 📄 **CV Analysis** - AI-powered resume optimization and feedback
- 🎙️ **Interview Practice** - Mock interview scenarios for role preparation
- 💬 **30-Second Pitch** - Generate professional elevator pitches
- 📝 **Knowledge Quizzes** - Test yourself on job-specific topics
- ✉️ **Cover Letter Generator** - AI-generated motivation letters
- 📈 **Salary Insights** - View average salaries across Mexican industries
- 📱 **Mobile Optimized** - Fully responsive design for all devices

## 💡 How to Customize

### Change Location Default
Edit line 227 in `index.html`:
```html
<input id="global-location-input" type="text" value="YOUR_CITY, STATE"
```

### Add More Job Roles
Add new `<option>` in the role selector (lines 215-221):
```html
<option value="Your Role">Your Role</option>
```

### Modify Salary Data
Update the Chart.js data (lines 336-341):
```javascript
data: [salary1, salary2, salary3],
```
